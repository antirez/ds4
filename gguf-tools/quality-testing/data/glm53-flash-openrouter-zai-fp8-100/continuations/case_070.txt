# Mediana di tre numeri

```python
def mediana(a, b, c):
    return sorted([a, b, c])[1]
```

**Esempio d'uso:**

```python
print(mediana(3, 1, 2))   # Output: 2
print(mediana(10, 5, 8))  # Output: 8
print(mediana(7, 7, 3))   # Output: 7
```
