Checksums catch accidental corruption because they condense a block of data into a small numeric value computed from the data's contents, so any change to the data—such as a flipped bit from a transmission error or storage fault—almost always alters the resulting checksum. The sender computes the checksum and sends it along with the data; the receiver recomputes it from the received data and compares. If the values differ, the receiver knows something changed in transit.
