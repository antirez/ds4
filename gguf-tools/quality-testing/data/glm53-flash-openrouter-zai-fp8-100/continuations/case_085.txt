A compiler uses an abstract syntax tree (AST) as a hierarchical, tree-shaped representation of a program's structure, built during the parsing phase after the source code is tokenized. Each node in the tree represents a syntactic construct—such as an expression, statement, variable declaration, or function definition—with parent-child relationships capturing how these constructs nest (for example, an assignment node might have child nodes for the variable being assigned and the expression computing its value). Unlike the concrete syntax tree, the AST omits irrelevant details like punctuation and parentheses, focusing instead on semantic structure.
